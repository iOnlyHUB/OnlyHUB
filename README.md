# 🌍 About OnlyHUB

**OnlyHUB** is a modern charitable platform built on **WordPress** that simplifies collecting, managing, and distributing humanitarian aid.

The project aims to unite volunteers, charitable organizations, donors, businesses, and people who need assistance into one transparent digital ecosystem.

---

# 🎯 Mission

Create a reliable and transparent platform that makes helping others easy, fast, and accessible to everyone.

---

# ✨ Core Features

- ❤️ Collection of charitable donations
- 📦 Distribution of humanitarian aid
- 👥 Volunteer management
- 📰 News and announcements
- 🎵 Media integration
- 🏢 Business partnerships
- 📍 Interactive assistance map
- 🔍 Transparent aid tracking
- 📈 Donation statistics
- 📱 Fully responsive interface
- 🌐 Multilingual support
- 🔐 Secure authorization

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/iOnlyHUB/OnlyHUB.git
```

## Enter project

```bash
cd OnlyHUB
```

## Run Docker

```bash
docker compose up -d
```

Open

```
http://localhost
```
