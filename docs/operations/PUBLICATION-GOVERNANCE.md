# OnlyHUB Public Information Governance

This policy defines the minimum controls for publishing campaigns and reports on `only-hub.org`.

## Publication states

1. **Draft** — visible only to authorised editors and coordinators.
2. **Internal review** — programme facts, ownership and supporting files are checked.
3. **Verified** — an authorised editor confirms that the campaign may be listed publicly.
4. **Published** — the approved record is available on the website.
5. **Closed or corrected** — the public status or material facts are updated while the administrative audit trail is retained.

## Campaign gate

Before setting the campaign verification flag, the reviewer must confirm:

- responsible OnlyHUB owner;
- public title, purpose and beneficiaries;
- approved start and end dates;
- verified currency and financial target, if displayed;
- approved imagery and rights to publish it;
- privacy-safe copy with no unnecessary personal data;
- a valid public report link when a report is claimed;
- legal and banking approval before any payment control is enabled.

The Support page lists only published campaigns with the verification flag. Payment processing remains a separate final-stage release gate.

## Report gate

The Transparency Centre lists a report only when:

- its campaign is published;
- the campaign verification flag is active;
- the report URL is present and uses an approved public destination;
- the file contains no secrets, private applicant information or unapproved personal data;
- totals and outcomes are traceable to an accountable internal source.

Removing verification or the public report URL automatically removes the report from the public listing.

## Corrections

Material corrections must identify the responsible editor, the affected campaign, the reason for the change and the approval source. Administrative status changes must remain available in the protected audit log. Public copy must not imply that draft or placeholder figures are verified.

## Access

- Administrators manage platform configuration and roles.
- Editors and authorised coordinators manage reviewed public content.
- Applicants, volunteers, donors and partners cannot publish campaigns or reports.
- Production credentials, private evidence and applicant records are never stored in public post content.
