# OnlyHUB Brand Asset Checklist

The following materials were approved by the project owner and must be used as official visual sources. They must not be recreated, renamed inconsistently or replaced with third-party marks without approval.

## Required logo families

- OnlyHUB Foundation
- OnlyHUB Business
- OnlyHUB News
- OnlyHUB Media
- OnlyHUB Music
- OnlyHUB Healthcare
- OnlyHUB Clinical Service
- OnlyHUB Defence Support
- OnlyHUB Stop War
- OnlyHUB Innovation
- OnlyHUB Production

## Required web variants

For every family, prepare:

- original master file;
- transparent PNG at 1x and 2x;
- optimized SVG where source quality permits;
- light-background variant;
- dark-background variant;
- square social avatar;
- favicon/PWA crop where legible.

## Naming convention

```text
assets/images/brand/onlyhub-{direction}-logo.svg
assets/images/brand/onlyhub-{direction}-logo-dark.svg
assets/images/brand/onlyhub-{direction}-avatar.png
```

Use lowercase Latin slugs and hyphens. Example: `onlyhub-defence-support-logo.svg`.

## Homepage hero

The approved main building image should be exported as:

```text
assets/images/home-hero-ecosystem.webp
assets/images/home-hero-ecosystem.jpg
```

Recommended delivery sizes:

- 1920 × 1080 desktop;
- 1280 × 960 tablet;
- 768 × 1024 mobile crop.

## Current limitation

The repository currently contains the implementation references and filenames, but the original uploaded image binaries are not available to the GitHub connector in this workspace. They must be uploaded to the repository or supplied as downloadable source files before the final branded release can be declared complete.

## Acceptance checks

- no visible compression artifacts;
- no text distortion;
- correct spelling of each direction;
- transparent edges are clean;
- minimum contrast is preserved;
- copyright and ownership are confirmed;
- every asset is under the repository size policy.
